# HousingPulse Group Project

## Description
This project is an interactive dashboard that analyzes rent, housing prices, and affordability across U.S. states over time.

It allows users to filter by state and year, view trends, compare affordability, and explore the relationship between rent and the Housing Price Index (HPI).

The dashboard uses real-time data and visualizations to highlight key insights and patterns in housing affordability.

## Language
Python

## Libraries
Streamlit, pandas, matplotlib, numpy
